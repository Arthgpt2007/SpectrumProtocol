SPECTRUM PROTOCOL
A first-person colour-theory puzzle, stealth, and action game built in Unity 6.
About the Game
Spectrum Protocol takes place inside a malfunctioning futuristic laboratory. As a nanobot equipped with colour-based abilities, your mission is to navigate the facility, solve colour puzzles, evade or disable security drones, and restore the central reactor.
The environment uses a primarily grayscale sci-fi aesthetic, while interactive systems use vibrant colours to communicate gameplay.
Gameplay
The game is divided into three connected areas:
Level 1 — RGB Calibration
Use red, green, and blue light switches to create the required output colour and unlock security gates. For example, red + green = yellow.
Level 2 — Ghost Frequency
Navigate the surveillance sector while avoiding security drones. Change your camouflage colour to match designated hiding zones. Disable shield generators with the complementary laser colour to unlock the exit.
Level 3 — Chromatic Core
Overcome the final security systems and restore the central reactor. Solve the last puzzle by selecting three neighbouring colours on the reactor's six-colour wheel.

Colour Mechanics
- Additive RGB mixing: Combine light channels to unlock colour-coded gates.
- HSV camouflage: Match your colour to a hiding zone to avoid drone detection while inside it.
- Complementary-colour combat: Break an energy shield with its designated opposite colour, then attack exposed drones. Disable all required generators to open security gates.
- Analogous colour harmony: Select three adjacent colours on the reactor wheel to complete the mission.

How to Play (Windows Build)
1. Download and extract the entire Windows build archive.
2. Keep the .exe, its _Data folder, and other included Unity runtime files together.
3. Run the game executable.
4. Select Start Game from the main menu.
5. Read each mission briefing, then complete all three levels.
Note: The executable alone is not sufficient; do not separate it from the accompanying build files.
